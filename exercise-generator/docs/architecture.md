# 题库与单元模块约定

## 新增题型

1. 在 `data/question-bank.js` 为题型登记唯一 `id`、显示名、`pointId`、难度 `tier`（1、2、3）、生成器名称和参数。题库参数保持为可审阅的数据，不在这里计算答案。
2. 在相应的 `units/*.js` 中实现生成器。它接收题型定义与核心工具，返回 `prompt`、`answer`、`board`、`analysis` 和 `hint`。
3. 为题目选择已有 `pointId`，或在 `data/knowledge-points.js` 新增概念说明、解题策略和易错提醒。
4. 在 HTML 脚本区按“题库与知识点 → 单元模块 → 核心 → 粉笔引擎 → 板书脚本 → 页面”的顺序加载新资源。
5. 将页面与带版本号的脚本、样式加入根目录 `js/pwa-config.js` 的预缓存清单，并同步发布缓存版本。

## 数据约定

- 单元 ID 使用稳定的英文短名；重复名称合并到同一个 ID。
- 题型 `id` 在单元内唯一，`pointId` 必须能在知识点目录中找到。
- 每轮每类题型出现 3 次：按 `tier` 从 1 到 3 递进，每层分三遍随机抽题；固定例题每轮轮换数值。新增题型必须指定层级，固定例题至少提供 3 组。
- 生成核心会检查题型是否有对应知识点，以及题目、答案、解析、板书脚本是否齐全。
- 每题答案使用字符串，解析按步骤排列，知识点和提示均以纯文本展示。
- `board.kind` 为 `mul`、`div` 或 `lines`；前两者由竖式引擎逐笔生成，后者按行保留等式变形。
- 小数运算优先转换成整数系数与十进制位数，避免浮点误差。
- 当前题库是无服务端依赖的静态实现；所有抽题与判分都在浏览器本地完成。
