# 本期知识点

## 小数乘法

| 知识点 | 内容与策略 | 常见错误 |
|---|---|---|
| 因数小数位数与积的定位 | 先按整数乘法求积；按两个因数的小数位数之和从整数积右边起定位，最后可去掉小数末尾的 0。 | 只数一个因数的小数位，或点小数点前就删 0。 |
| 小数乘整数 | 先按整数乘法计算，再按小数因数位数定位。 | 漏写进位或数错小数位。 |
| 小于 1 的因数与积的大小 | 正数乘大于 1 的数，积变大；乘 0 到 1 之间的数，积变小。 | 认为乘法一定会让积变大。 |
| 积末尾的 0 | 点好小数点后，依据小数性质去掉积末尾的 0。 | 点小数点以前就删 0，造成数位错位。 |
| 乘法关系中的未知因数 | 已知积和一个因数，用积除以已知因数求另一个因数，再代回验算。 | 把已知因数除以积，或忘记验算。 |
| 乘法分配律 | 把一个因数拆成两部分的和，分别相乘后把积相加。 | 拆分后漏乘一项。 |
| 乘法结合律 | 多个数相乘时先找能凑整的两对，改变分组但不漏因数。 | 改变分组时漏乘因数。 |
| 积的近似数 | 先算准确积，再看保留位数的下一位，使用约等号。 | 提前舍入，或把近似数写成等号。 |
| 面积模型、单价与数量 | 面积 = 长 × 宽；总价 = 单价 × 数量；找零 = 付款 − 总价。列式后核对结果单位。 | 把相乘关系写成相加，或漏写面积、货币单位。 |

## 小数除法

| 知识点 | 内容与策略 | 常见错误 |
|---|---|---|
| 小数除以整数 | 逐位试商；除数为整数时，商的小数点与被除数对齐。 | 漏点商的小数点。 |
| 0 占位与添 0 | 某一位不够除，商的该位写 0；原有数位用完仍有余数时，可在被除数末尾添 0 继续除。 | 跳过商中的 0，或认为添 0 后必定除尽。 |
| 除数是小数 | 两数同时扩大相同倍数，让除数变整数；被除数位数不足时补 0。 | 只移动除数的小数点。 |
| 商的大小和近似数 | 先比较除数与 1；保留两位小数需除到千分位，再四舍五入。 | 把近似商写成精确等式。 |
| 循环小数 | 余数重复时商循环；重复的最短数字组是循环节。 | 把截下的几位小数当成完整准确值。 |
| 实际取整 | 根据情境选进一、去尾或四舍五入。 | 一律机械四舍五入。 |

## 简易方程

| 知识点 | 内容与策略 | 常见错误 |
|---|---|---|
| 用字母表示数量 | 相同单价用 x 表示，几份写成几 x；固定费用另计，最后合并同类项。 | 把固定费用误当 x 项，或漏写一次购买。 |
| 两步方程与等式性质 | 按逆运算顺序撤销加减、乘除，每一步都对等式两边做相同操作。 | 只改变一边，或先后顺序弄反。 |
| 一步方程 | 认清未知数的位置，再让等式两边同时做逆运算。 | 见到减法或除法就套固定公式。 |
| 合并同类项 | 先合并含 x 的项，再按等式性质变形。 | 把常数项与 x 项直接合并。 |
| 减法中的未知数位置 | 识别被减数、减数、差；未知数是减数时，用被减数减差。 | 未区分未知数是被减数还是减数。 |
| 从数量关系列方程 | 先声明未知量，再用总价、倍数、速度 × 时间 = 路程等关系建立等式。 | 字母含义不清，或关系式运算颠倒。 |
| 代入验算 | 将解代回原方程，分别计算等号两边并确认相等。 | 只写 x 的值，没有检查原方程。 |

页面中的每道题都通过 `pointId` 关联到对应知识点；题目旁展示要点，展开解析时补充易错提醒。
