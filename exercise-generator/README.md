# 进阶练习生成器

独立的静态练习模块，沿用黑板、木框、粉笔槽和课堂模式切换的视觉语言。本期实现 **小数乘法、小数除法、简易方程** 三个单元；同名重复项合并。

## 目录

- `units/`：单元元数据与该单元的参数化题目生成器。
- `data/question-bank.js`：题型目录、知识点关联、参数范围与经过挑选的题目种子。
- `data/knowledge-points.js`：每个知识点的概念、解题策略与易错点。
- `js/generator-core.js`：按单元抽取题型、精确处理十进制乘积、校验作答。
- `js/board-steps.js`：把题目变成竖式或逐行等式板书，复用 `blackboard/` 的粉笔引擎。
- `js/app.js`：单元切换、教师/学生模式、历史题目、提示和逐步播放。
- `js/pwa-registration.js`：从子路径注册主站 service worker，复用离线缓存。
- `docs/`：修订大纲、知识点和题库扩展说明。

## 生成规则

小数乘法、小数除法、简易方程分别包含 11、8、11 类提高题型。每类题型在一轮中出现 3 次，因此三单元每轮分别有 **33、24、33 道题**。题型按三层难度依次出现，同层内分三遍洗牌；固定例题在本轮内不重复，完成一轮后再从第一层开始。题目参数由单元模块生成。小数乘法按整数系数和小数位数计算，避免依赖二进制浮点数定位小数点。每题记录题型、难度层级、知识点 ID、答案、板书脚本、分步解析和提示。

“继续板书”每按一次只写一步；竖式保留在板上，简短提示擦掉重写。学生模式可以先作答，完整文字解析按需展开。输入整数或小数时支持全角数字和末尾零等价写法。

内容顺序与审查记录见 [`docs/curriculum-outline.md`](docs/curriculum-outline.md)。

## 本地运行

从项目根目录启动静态服务器：

```powershell
python -m http.server 4187 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4187/exercise-generator/`。页面所需资源已加入项目的 PWA 预缓存清单。
